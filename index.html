Ayarlar

WASD: hareket · Shift: koşu
Fare / ok tuşları: nışan
Sol tık veya Boşluk: şut (basılı tut = güç)
F: pas · V: havadan pas
G: müdahale · G+G: kayarak müdahale
Q / E: falsolu şut
R: topu sıfırla (antrenman)
Esc: duraklat
Mobil: sol joystick = hareket, sağ ekranı sürükle = nışan, ŞUT'a basılı tut + sola/sağa kaydır = falsolu şut
Duran toplarda şut / F / V'ye basınca oyuncu otomatik vurur
